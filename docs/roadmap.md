# Roadmap

## Current prototype status

The public GitHub Pages build is now a calendar-first interaction prototype. It supports click-to-add, click-to-edit, owner reassignment, one-off/weekly recurrence choices, proposal review, navigation menus, workload counts, JSON-file preview messaging, and localStorage demo persistence. It does not yet provide accounts, shared persistence, real imports, or calendar write-back.

## MVP

- Two organizer accounts and one household
- Leo, Elliott, and Matilde household records
- Weekly calendar, events, recurring events, tasks, and assignments
- Suggested versus confirmed work-from-home days
- Obfuscated work annotations
- Proposal inbox with approve/edit/reject/defer actions
- Deterministic conflict and unassigned-responsibility warnings
- JSON file import and reviewed import history

## Later

- Authenticated API import from the work planning assistant
- Calendar export or controlled read-only calendar integrations
- School meal records, preparation reminders, weekly shopping, and groceries
- Notifications, caregiver roles, and richer recurrence rules

AI suggestions remain advisory until the organizers explicitly approve them.
